# Student_Record_Management_System-Using_Singly_Linked_List.

##Project Overview

The objective of this project is to develop a menu-driven Student Record Management System using C programming and a singly linked list. It provides hands-on experience with data structures, pointers, dynamic memory allocation, structures, and linked list operations. Student records are dynamically managed without using fixed-size arrays.

✨ Features
- Insert student records at the beginning.
- Insert student records at a specific position.
- Insert student records at the end.
- Delete student records by position.
- Display all student records.
- Search and update student details using student ID.
- Count the total number of students.
- Reverse the singly linked list.
- Menu-driven interface for continuous operations.
- Dynamic memory allocation using malloc() and free().

  🛠 Technologies Used
- C Programming
- GCC Compiler
- Linux Operating System
- Data Structures

 📚 Libraries Used
- stdio.h
- stdlib.h
- string.h

📖 Data Structure Used
   Singly Linked List

Each student node contains:

  - id	  -        Student ID

  - name	 -       Student name

  - marks	  -      Student marks

  - next	  -      Pointer to the next node

🔧 Functions Used
- malloc() – Dynamically allocates memory for new nodes.
- free() – Releases allocated memory.
- printf() – Displays student information.
- scanf() – Reads student details.
